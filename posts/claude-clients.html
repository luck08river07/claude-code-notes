Claudeはどこで使える？ ― Web・デスクトップ・スマホ・Claude Codeの違い

2026-05-10 ・ 入門 Claude クライアント比較

学習を進めるなかで、「Claudeって claude コマンドだけじゃないんだ」と気付きました。実はAnthropicは複数のクライアントを提供していて、用途によって向き不向きがあります。今回はその整理メモです。

Claudeを使えるクライアントは大きく4つ

調べてみると、自分が触れる範囲では次の4つがありました。

  1. Webブラウザ版（claude.ai）
  2. デスクトップアプリ（Mac / Windows）
  3. スマホアプリ（iOS / Android）
  4. Claude Code（ターミナルから動くコーディング向けツール）

「同じClaude」がどこからでも使える、というのが基本の考え方ですが、それぞれ得意なことが少しずつ違います。

1. Webブラウザ版（claude.ai）

もっとも手軽な入り口です。claude.ai にアクセスしてログインすれば、すぐにチャットを始められます。

  • インストール不要、URLを開くだけ
  • 会話履歴が同じアカウントで共有される
  • ファイルや画像を添付して相談できる
  • Artifactsでコードや文書をその場で生成・プレビュー可能

「とりあえず触ってみたい」「外出先のPCから使いたい」というときに便利でした。

2. デスクトップアプリ（Mac / Windows）

ブラウザを開かずに、PCのアプリとして起動できる版です。中身はWeb版と近いですが、常駐アプリとして使えるぶん使い勝手が変わります。

  • ショートカットからすぐ呼び出せる
  • ウインドウとして独立しているので、調べ物中のブラウザと混ざらない
  • ファイル選択やフォルダとの連携がしやすい

普段からPCで作業する人は、デスクトップ版を入れておくと「ちょっと聞きたい」のハードルが下がります。

3. スマホアプリ（iOS / Android）

iPhoneやAndroid向けのアプリも提供されています。

  • 移動中や思いついたタイミングですぐ使える
  • 音声入力で話しかけるように相談できる
  • カメラで撮った写真をその場で共有できる

個人的には「移動中にアイデアを壁打ちする」「読んでいる本の写真を撮って質問する」といった、PCを開くほどではない場面で重宝しそうです。

4. Claude Code（ターミナル版）

そしてこのブログの主役、Claude Codeです。前回の記事でも触れましたが、立ち位置がほかとはかなり違います。

  • ターミナルから claude コマンドで起動
  • ローカルのファイルを読み書きできる
  • シェルコマンドを実行してテストやビルドまで任せられる
  • プロジェクト単位の作業を一緒に進める「相棒」のような使い方

Web/デスクトップ/スマホが「会話して相談する」場だとしたら、Claude Codeは「実際に手を動かして作業する」場、というのが今のところの理解です。

違いをざっくり比較

クライアント 得意なこと 向いている場面
Webブラウザ版 気軽に始められる・どこでも使える 初めての利用・出先のPC
デスクトップアプリ すぐ呼び出せる・常駐できる 普段のPC作業中の相談
スマホアプリ 音声入力・カメラ連携 移動中・写真を見せて質問
Claude Code ファイル操作・コマンド実行 コーディング・プロジェクト作業

同じアカウントで使い分ける

これら4つは、同じAnthropicアカウントでログインして使えます。会話履歴も基本的にアカウントに紐づくので、

スマホでアイデアをメモ → PCのデスクトップ版で続きを相談 → Claude Codeで実装

のような流れも自然にできそうです。「どれか一つだけ」ではなく、用途で使い分けるのが正解みたいです。

学習者としての使い分けメモ

自分はこれからこんな使い方をしてみようと思っています。

  • Web/デスクトップ版 ：学習中に分からない概念を整理してもらう、文章をまとめる
  • スマホ版 ：移動中に「気になった言葉」を音声で質問してメモ
  • Claude Code ：実際にコードを書いたり、リポジトリを操作したりする

まとめ

Claudeには Web・デスクトップ・スマホ・Claude Code の4つの入り口があり、どれも同じAnthropicアカウントで使えます。「相談する」場面と「作業する」場面で使い分けると、学習も実作業も効率が上がりそうです。
